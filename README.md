## 📱 Sobre o App

O **Chef Click** permite ao usuário:

- Navegar por uma lista de pratos
- Visualizar os detalhes do prato selecionado
- Adicionar ao carrinho
- Simular uma finalização de pedido

Tudo com uma interface amigável e moderna (porém ainda em desenvolvimento).

## 📂 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/chef_click.git

# Entre na pasta do projeto
cd chef_click

# Instale as dependências
flutter pub get

# Execute o app
flutter run
```
